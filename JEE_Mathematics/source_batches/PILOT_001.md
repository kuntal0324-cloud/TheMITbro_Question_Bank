# JEE Mathematics Production Pilot 001\n\nOriginal pilot content; not yet approved for sale.\n\n### JEE-M-P001\n**Exam:** JEE_MAIN  \n**Subject:** Mathematics  \n**Topic:** Calculus  \n**Difficulty:** Medium  \n**Type:** MCQ\n\nIf $f(x)=x^3-3x$, then the number of points in $[-2,2]$ at which the tangent to $y=f(x)$ is parallel to the $x$-axis is\n\nA. 0  \nB. 1  \nC. 2  \nD. 3\n\n**Answer:** C\n\n**Detailed Solution:** $f'(x)=3x^2-3=3(x^2-1)$. Hence $f'(x)=0$ at $x=\pm1$, both in the interval.\n\n---\n\n### JEE-M-P002\n**Exam:** JEE_MAIN  \n**Subject:** Mathematics  \n**Topic:** Coordinate Geometry  \n**Difficulty:** Medium  \n**Type:** NAT\n\nThe circle $x^2+y^2-6x+8y+9=0$ has radius ______.\n\n**Answer:** 4\n\n**Detailed Solution:** Completing squares gives $(x-3)^2+(y+4)^2=16$, so the radius is 4.\n
